📘 Shopping-Cart-System\

📌 Project Overview

* The Simple Billing System is a Python-based application that allows users to enter item prices continuously and generates a final bill with applicable discounts. The system ensures proper validation of inputs and provides a clear summary including subtotal, discount, and final payable amount.
* This project demonstrates core programming concepts such as loops, conditional statements, input validation, and basic calculations.

🎯 Objective
* To build a basic billing system using Python
* To handle continuous user input using loops
* To apply discount logic based on total purchase amount
* To generate a clear and structured bill summary

⚙️ Tools & Technologies Used
* Python – Core programming language
* Google Colab 

🛠️ What I Have Done
* Implemented a while loop to continuously accept item prices
* Used a sentinel value (0) to stop input collection
* Validated inputs to ensure no negative prices are accepted
* Maintained:
  Total number of items
  Subtotal amount
* Applied conditional discount logic:
   20% for subtotal ≥ 1000
   10% for subtotal ≥ 500
   5% for subtotal ≥ 200
   No discount below 200
* Calculated:
   Discount amount
   Final payable total
* Displayed a well-formatted bill summary

📚 Conclusion

* This project provides a practical understanding of how billing systems work by combining input handling, validation, and business logic. It serves as a strong foundation for developing more advanced applications such as retail billing software or e-commerce systems.
